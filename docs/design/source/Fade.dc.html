Teaching illustration 03 · Fading the guide

The keyboard disappears one key at a time.

Each key fades on its own schedule as the learner masters it, and steps back if accuracy slips. Four snapshots of one learner's on-screen keyboard.

Day 1 · Home row {{ cA }}

Full guide on the 8 home keys. Everything else is locked and greyed out.

Day 4 · First reaches {{ cB }}

Home keys step down to colour only, then to an outline, while accuracy holds above 95%. R and U are brand new.

Week 2 · Home row gone {{ cC }}

The home row is no longer drawn at all. Newly unlocked keys still arrive with the full guide.

Week 4 · Eyes up {{ cD }}

Most keys are invisible or bare outlines. The learner reads the screen, not the keyboard.

D L0 full guide
D L1 colour only
L2 outline
