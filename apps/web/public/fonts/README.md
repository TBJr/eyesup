# Bundled fonts

- **Atkinson Hyperlegible** — Braille Institute of America, SIL Open Font Licence 1.1 (`AtkinsonHyperlegible-OFL.txt`).
- **JetBrains Mono** — JetBrains, SIL Open Font Licence 1.1 (`JetBrainsMono-OFL.txt`).

Both are bundled with the app. The web Content Security Policy does not allow loading fonts from a CDN.
